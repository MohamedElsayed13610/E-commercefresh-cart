# FreshCart E-Commerce Web App

A complete responsive e-commerce application built with **React + Vite** and the Route E-commerce API.

## Features

- User registration, login and logout
- Forgot-password and reset-password flow
- Product catalog with search, sorting and filters
- Category and brand browsing
- Product details pages
- Protected wishlist
- Shopping cart with add, remove, quantity update and clear actions
- Cash and online checkout flows
- Order history and payment-status views
- Product pagination
- Loading, empty and error states
- Toast notifications and form validation

## Tech Stack

- React 18
- Vite
- React Router
- TanStack React Query
- Axios
- Formik
- Yup
- React Hot Toast
- Lucide React

## API

The application uses the Route E-commerce API for authentication, products, categories, brands, wishlist, cart and checkout operations.

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

A Vercel SPA rewrite is included for client-side routing in production.
